tools++: MCP Server with 55 Tools for Claude (Math, Dates, CSV, SQLite, PDF)

An MCP server with 55 small tools so Claude stops guessing: exact math, dates and holidays, CSV, SQLite, PDF, archives, ports, ffmpeg.

View on GitHubDocumentation

tools++ is a zero-dependency MCP server with 55 tools for Claude Code, Claude Desktop, Cursor and other MCP clients: exact calculator, dates and public holidays, CSV and SQLite queries, PDF text, archives, ports and ffmpeg helpers. Only needs Node.js.

Features

Exact math

calc with fractions and big integers, solve, matrix, stats, finance, unit and currency conversion.

Dates that are right

Current time, time zones, business days, public holidays (Germany with all states and more), cron.

Data

CSV and table queries, SQLite, JSON and schema tools, PDF text.

Files and system

Archives, diffs, duplicates, disk usage, ports, processes.

Media

ffmpeg helpers for media info, frames and audio analysis.

Lightweight

No dependencies, only Node.js. Schemas load on first use, so it costs almost nothing in context.

Install

/plugin marketplace add Kessler833/tools-plus-plus
/plugin install tools-plus-plus@tools-plus-plus

Full instructions, requirements and troubleshooting are in the README on GitHub.
